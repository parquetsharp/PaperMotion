# PaperMotion Study Companion 0.1.0 Candidate

- Microsoft Edge sidebar for PDF import, document chat, flashcards, quizzes, and concepts.
- Local engine pairing with scoped study API access, token expiry, and revocation.
- Direct import from ordinary PDF URLs; optional per-origin permission and local-file/file-picker workflows.
- Full local web viewer for animation, formulas, plots, 3D scenes, input-adjustable algorithm simulation, and feedback-driven revisions with undo.
- GitHub Copilot CLI and configurable alternative provider support in the companion engine.
- Bundled license notices and versioned source/extension packages.

This candidate has not been submitted or certified. It needs the separate local engine and an authorized AI connection. See READINESS.md and SECURITY-REVIEW.md for unresolved release gates. Existing store identities, customer installations, and signed-installer upgrades have not been validated.
